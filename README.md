# gamepad-input-bridge

手柄输入采集与事件转换工具，优先在 Windows 下适配，为后续程序提供统一的输入数据。

> 当前处于开发准备阶段：已通过临时诊断脚本验证首个设备的部分基础输入，正式 C++ 采集程序与长短按事件尚未实现。

## 首期目标（待实现）

- 读取设备可提供的身份信息和连接状态。
- 采集按键、方向键、左右摇杆和扳机的原始状态。
- 记录按下、松开、时间戳与按住时长，生成短按、长按事件。
- 提供统一的数据输出，方便后续程序接入；具体接口随实现确定。

设备信息和额外按键的可读取范围，以手柄在 Windows 下实际暴露的输入接口为准。长按、短按由程序根据按键时序判断，阈值计划支持配置。
